Starting a Prophane analysis you can choose between a standard analysis and an expert mode. The standard analysis consists of a taxonomic analysis based on the NCBI-non redundant database and a functional analysis based on the eggnong database. The standard analysis needs minimal input: the protein identification file and associated protein sequence fasta file. The expert mode allows detailed customizations of each workflow step and the selection of various annotation databases and search algorithms. In addition, sample groups, quantification algorithm and lca algorithm can be determined. Input Files

The minimum input for a prophane analysis consists of a proteomic search result file and the matching FASTA file. The input format of the proteomic search result file must be selected in the tab 'Source'. In the Exclude tab proteins, e.g. contaminations can be excluded from the analysis based on the accessions. If all input files are selected and only the standard analysis is to be run, the job can be submitted in the next step by pressing the Submit by pressing the Submit button. If the expert toggle is activated, all tasks can be specified in detail. Step by step instruction: 1. Name your new Prophane job 2. Choose the correct input format for the protein identification file 3. Choose the identification file for upload 4. Choose the matching FASTA file for upload 5. Exclude Proteins from your analysis by string matching.

Report files

The report file is the protein identification file of the mass spectrometry analysis and must contain information about protein groups (also known as metaprotein or protein-families). Prophane supports various different input formats, as listed below. If you plan to use another input format on a regulary basis, please contact us. So far, Prophane supports proteomic search result data provided in:
  • generic input format
  • mzTab format
  • mzIdent1.2 format
or produced by the search software:
  • MetaProteome Analyzer in single or sample comparison format
  • Proteome Discoverer protein group output
  • Scaffold
Weitere report file typen können auf Anfrage (support@prophane.de) hinzugefügt werden.

FASTA file

Plain or gzipped FASTA file containing sequences of all identified proteins. The protein accessions/IDs have to be the same as used in the protein identification file. You can use the same fasta file as for the peptide-spectrum matching. If fasta file is too large, Prophanes runtime increases strongly. Ideally the fasta file contains all sequences contained in the identification file and not more. Sequence accession IDs should not contain any pipes ('|') to allow prophane a consistent processing of the data. Sequence IDs containing 2 or more '|', like Uniprot protein accessions, will be processed, e.g. from sp|O70558|SPR2G_MOUSE to 070558.

Exclude

The "Exclude" option specified in Input step can be used to exclude proteins from analysis by string matching. For example, if you have contamination proteins whose accessions start with "CON_", select "Accessions starting with" in the exclude field and enter CON_. Sample Groups In this section samples can be assigned to different sample groups. These sample groups are relevant for getting mean quantification values about different samples. This allows a comparison of different sample groups, e.g untreated samples vs. treated samples. Sample group mean quantification values are reported in the summary table and displayed in the Krona-Plots. The quantification values for each sample are reported additionally. If no groups are specified, quantification is carried out for each sample separately. Step by step instruction: 1. Click "Add Group" button 2. Name your sample group (e.g. "treated group"). The sample_groups names are arbitrary and can be chosen by the user as desired. 3. For every sample belonging to this group, add a new Sample Name by clicking '+' button 4. Enter correct sample name used in the protein identification file. 5. Check again if the sample name is spelled correctly. Taxonomic Annotation Taxonomic annotation searches the selected reference database for similar proteins, retrieves the associated taxon ID and specifies the entire taxonomic lineage of this protein. The search algorithm DIAMOND BLASTP searches for sequence homologies in the specified protein database. Prophane supports following protein sequence databases:
  • {{db.name}}
More informations about the different protein databases can be found here: databases Prophane reports always the taxonomic lineage of the protein with the highest scoring match. The evalue defines how similar the reported proteins have to be to be reported. The smaller the evalue, the more similar the protein match. For information regarding additional parameters, please check the DIAMOND documentation: https://github.com/bbuchfink/diamond/raw/master/diamond_manual.pdf How to define a taxonomic annotation task: 1. Name your task in Task Label field 2. Choose your preferred protein sequence database used for sequence homology search in 'Reference Database' field 3. Define evalue (the smaller, the stricter) 4. Optional: add advanced options by choosing an option and then click the '+' button How add a new taxonomic task: 1. click Add Task Button 2. name task and define the parameters How to remove a taxonomic task: Use the '-' button on the right side of the Task Label field. Custom Map Alternatively, a self-generated file can be used for taxonomic and/or functional annotation. ACCESSION based annotation using user provided mapping table. The acc2annot_mapper can be used to transfer any kind of annotation (functional or taxonomic) based on the protein accessions. Annotations are retrieved from a user-provided tab-separated table (tsv) file. Annotation level names are based on the column names of the user provided table (= column names). Avoid spaces, commas, tabulators, and semicolons. Example tables see help How to define a custom map task: 1. Name your task in Task Label field 2. Choose the custom map for upload from your file systeme in "Custom Map" field. Lowest Common Ancestor (LCA) The LCA approach searches in hierarchical data, which can be represented as a tree, for the lowest node, that is shared by all group members. Prophane defines for every functional or taxonomical annotation for every annotation level a LCA as representative for all protein group members. Often the different proteins of a protein group/metaproteins have different annotations. Since we want a common representative for all protein group members, Prophane determine a lowest common ancestor of them. more information about methods and parameters see x How to define a LCA method: 1. Choose the LCA method. Default is LCA per group 2. If LCA per group is chosen, define the threshold value. Default is 1. 3. Optional: add advanced options via choose Option and Click the '+' button. How to remove a parameter: Use the '-' button on the right side of the parameter field. Submit Check your input files and task definition are correct. Then click 'submit' button. Depeneding on you queue position, starting a prophane job can take some time. If the Prophane job is complete, you get an Email notification and can download the results.
