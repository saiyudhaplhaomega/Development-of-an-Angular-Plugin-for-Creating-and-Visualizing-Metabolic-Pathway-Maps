About Prophane Prophane provides a tailored and fully automated workflow for metaproteomics analysis with special focus on metaprotein annotation.
For this, Prophane supports inputs from different programs such as MetaProteomeAnalyzer (transfer: metaprotein report), Scaffold (transfer: protein report), Proteome Discoverer (transfer: protXML and PSMS.txt) and a generic format (tabular). Workflow Description

In metaproteomics, protein identifications can be ambiguous when a identfied peptide (or subset of identfied peptides) can be assigned to more than one protein. The most common approach is, to group these ambiguous identifications to so-called protein groups (synonyme: metaprotein, protein family). Prophane provides consistent protein annotation based on sequence homology and condensates metaprotein annotation based on a lowest common ancestor approach (LCA). Moreover, quantitative data is provided in a sample-specific manner based on normalized spectral abundance factors (NSAF). While the standard analysis needs minimal input, an expert mode is available allowing detailed customizations of each workflow step and the selection of various annotation databases and search algorithms.
